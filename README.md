# ClickbaitGuard

## Решаемая проблема

Распространение в цифровых медиа сенсационных, преувеличенных и вводящих в заблуждение заголовков (кликбейта), а также материалов, где заголовок искажает или прямо опровергает фактическое содержание статьи. Это приводит к когнитивной перегрузке аудитории, росту дезинформации и падению доверия к новостным платформам. Ручная проверка потока публикаций модераторами не масштабируется из-за огромного объема контента.

## Quickstart

### 1. Добавьте токен для доступа к API НКРЯ

Создайте в корневой папке репозитория файл `ruscorpora_api_key.txt`, после чего поместите в него свой токен для доступа к API НКРЯ.

### 2. Установите используемые python-библиотеки

Создайте `venv` с попшкомандой `python -m venv venv`

Активируйте `venv` с помощью команды `venv/Scripts/activate`

Установите библиотеки с помощью команды `pip install -r requirements.txt`

## Структура репозитория

По мере разработки проекта, структура может меняться.

### `/src/`

В эту папку кидаем **программные файлы со сбором данных и их обработкой**.

### `/tests/`

В эту папку кидаем **разного рода тесты** _(если они потребуются)_

### `/public/`

В эту папку кидаем **статичные файлы**. 

_Например, таблицы с данными, картинки, db._

### Остальные файлы

#### `/requirements.txt`

Требующиеся пакеты для Python.

Чтобы установить указанные пакеты, напишите комманду: ```pip install -r requirements.txt```

#### `/ruscorpora_api_key.txt`

Файл, который требуется создать и вставить в него свой токен для доступа к API НКРЯ.
